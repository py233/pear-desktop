# Pear Desktop Personal

Unofficial personal build of Pear Desktop with bilingual lyrics and lyrics translation features.

This repository is based on [ArjixWasTaken/pear-desktop](https://github.com/ArjixWasTaken/pear-desktop), which itself continues the MIT-licensed [pear-devs/pear-desktop](https://github.com/pear-devs/pear-desktop) project. It is not affiliated with, endorsed by, or maintained by the upstream projects.

## Why This Exists

The translation feature touches several parts of the synced lyrics plugin and is too large to be a comfortable single upstream PR. This repository keeps my full working version available without implying upstream maintenance commitments. Smaller pieces can still be proposed upstream separately later.

## Highlights

- Whole-song LLM translation: sends the full lyrics and song context to the model, then aligns the translated result back to each lyric line.
- Same-language skip: if the lyrics text is already in the target language, no translation provider is called.
- NetEase lyrics provider with official Chinese translation preference when target language is Chinese.
- Google Translate provider through an unofficial no-login endpoint.
- OpenAI-compatible provider, including Ollama-compatible endpoints.
- Local CLI provider for already logged-in Claude Code, Codex, or Gemini CLI.
- Smaller synced lyrics font-size options.
- Restored Arjix adblocker baseline.

## Downloads

Use the GitHub Releases page for packaged builds. Release artifacts are built and published by GitHub Actions from this repository. Windows releases include both an offline Setup installer and a portable `.exe`.

I have only tested this personal build on macOS 15.6.1. Windows and Linux artifacts are generated by GitHub Actions and need user testing.

For manual builds:

```bash
pnpm install
pnpm dev
```

Production build:

```bash
pnpm build
```

## Translation Providers

### OpenAI-Compatible

Use this for OpenAI-style endpoints. Ollama generally works with:

```text
Base URL: http://127.0.0.1:11434/v1
API mode: auto or chat-completions
Model: your Ollama model name
```

### Local CLI

The Local CLI provider assumes you are already logged in locally. It only asks which engine to use:

- Claude Code
- Codex
- Gemini CLI

The command and model are automatic. The CLI decides its own default model.

### Chinese Official Lyrics

When the target language is Chinese, the plugin tries official Chinese translations from NetEase first. If no good match is found, it falls back to the selected translation provider.
